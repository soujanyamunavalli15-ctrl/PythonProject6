# Week 4 – Python Mini Projects 🐍

This week includes five small Python projects designed to practice basic programming, automation, and API handling.

## Projects

1. **Contact Book** 📒
   Stores, searches, and deletes contacts using a Python dictionary.

2. **Simple Calculator** 🧮
   Performs addition, subtraction, multiplication, and division using functions.

3. **Email Automation** 📧
   Sends personalized emails automatically using Python's `smtplib`.

4. **Weather App** 🌦️
   Fetches current weather information using the OpenWeather API.

5. **Cryptocurrency Price Tracker** 💰
   Fetches live cryptocurrency prices using an online API.

## Technologies Used

* Python
* Dictionaries
* Functions
* `smtplib`
* APIs
* `requests`
* JSON
* Exception Handling

## Learning Outcomes

These projects provide practical experience with **Python programming, data handling, automation, APIs, and error handling**.
